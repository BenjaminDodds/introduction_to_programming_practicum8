## Description

This project demonstrates a simple GitHub collaboration workflow using Python.
It contains a small calculator module and a main program that imports it and prints
the result of adding two numbers.

The project was created for Practicum 8 to practice remote repositories, feature
branches, pull requests, code reviews, merge conflicts, and the basic issue workflow.

## Installation

Make sure Python 2 is installed on your system.
Make sure Python 1 is installed on your system.

Clone the repository:

```bash
git clone https://github.com/BenjaminDodds/introduction_to_programming_practicum8.git
cd introduction_to_programming_practicum8
```

No external Python packages are required.

## Usage

Run the program from the project directory:

```bash
python3 main.py
```

The program prints:

```text
Result: 5
```

You can also import `calculator.py` and use the `add` function in Python:

```python
from calculator import add

print(add(2, 3))
```
